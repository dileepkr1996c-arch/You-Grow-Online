YOU GROW ONLINE - Static Site Images Guide
=========================================

This folder has been automatically constructed as requested to support static asset deployments.

HOW TO INTEGRATE AND USE LOCAL IMAGES:
-------------------------------------
1. Put any visual properties (such as your corporate PNG logo, customer avatars, or portfolio snapshot previews) into this "images/" folder.
2. In '/static-site/index.html' or '/static-site/js/data.js', find any image source tag (e.g., 'https://images.unsplash.com/photo-...') and replace the source path with a relative path referencing files in this directory.

EXAMPLE:
- Save your custom logo image as "images/my-logo.png" inside this folder.
- Inside index.html, update the image tag:
  <img src="images/my-logo.png" alt="My Brand Logo" />

This ensures offline-first absolute independence and fast performance on GitHub Pages!
